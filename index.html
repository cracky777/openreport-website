Questions

Is Open Report really free?

Yes. The self-hosted Community edition is free forever under the GNU AGPL-3.0: every feature, no user limit, no expiring trial. The hosted Cloud is a separate, optional service with a free tier and paid plans, for people who would rather not run a server.

How is it different from Power BI or Looker Studio?

You run it. The application sits on your infrastructure, queries your databases from there, and the data never travels to a vendor. Pricing is not per seat, so adding readers costs nothing. And the source is readable and forkable, which means the tool cannot be discontinued, re-priced or feature-gated out from under you. Point by point: Open Report vs Power BI, vs Looker Studio, vs Metabase.

Which databases can it connect to?

PostgreSQL, MySQL, Google BigQuery, Azure SQL and DuckDB. CSV and Excel files can be imported directly and are queried through DuckDB.

What do I need to self-host it?

Docker. One docker-compose.yml runs the published image (amd64 and arm64) as a single container: download it, generate three secrets, run docker compose up -d. A home server, a NAS or a Raspberry Pi is enough. You can also run it from source on a server with Node.js 22 or newer, with ./install.sh.

Does my data leave my servers?

Not when you self-host: the SQL runs from your own server against your own databases, and nothing is sent anywhere else. If you choose the hosted Cloud instead, it runs on European infrastructure in France.

Can I control what each person sees?

Yes. Row-level security filters the rows a user is allowed to read, at the semantic-model level, so it applies to every report built on that model. Workspaces and roles control who can view, edit or administer.

Can I use it at work, or in a commercial product?

Yes. The AGPL-3.0 permits commercial use. The one obligation it adds: if you modify Open Report and offer the modified version to others over a network, you have to publish those modifications under the same licence. Using it unmodified, internally or with customers, requires nothing of you.

Install it with Docker

Three commands on any machine that runs Docker.

# Get the compose file
mkdir openreport && cd openreport
curl -fsSL -o docker-compose.yml \
  https://raw.githubusercontent.com/cracky777/openreport/master/docker-compose.yml

# Generate the three secrets it needs
printf 'SESSION_SECRET=%s\nINTERNAL_TOKEN_SECRET=%s\nDATASOURCE_ENC_KEY=%s\n' \
  $(openssl rand -hex 32) $(openssl rand -hex 32) $(openssl rand -hex 32) > .env

# Start it
docker compose up -d

Then open http://localhost:3001. The first account created becomes the admin.

One container for amd64 and arm64, so a home server, a NAS or a Raspberry Pi will do. Everything is kept in the openreport-data volume; upgrade with docker compose pull && docker compose up -d. On a public host, add COMPOSE_PROFILES=https to .env for nginx and a Let’s Encrypt certificate.

From source instead: clone the repository and run ./install.sh (Node.js 22 or newer), as the README explains.
